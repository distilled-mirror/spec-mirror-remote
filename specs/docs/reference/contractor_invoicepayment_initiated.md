# contractor_invoice.payment_initiated

This event is triggered when an employer initiates payment on a contractor invoice
for the first time (transition to `pending_payment` from `issued` or `approved`).

The payload is stateless. Use the contractor invoice ID and employment ID to retrieve current details.
