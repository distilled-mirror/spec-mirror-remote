# Welcome to Remote API

Welcome to Remote API :confetti\_ball:

This page provides an overview of our API reference to help you quickly navigate and integrate with our system.

## Remote API

| Category                        | Description                                                                                                                       |
| :------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------- |
| Authentication                  | Manage user authentication that includes OAuth2and SSO Configuration.                                                             |
| Company Management              | Endpoints for managing company information, departments, and managers.                                                            |
| Country Management              | Access information about supported countries.                                                                                     |
| Benefits                        | Manage benefit offers, renewal requests, and offers tied to employment.                                                           |
| HRIS                            | Track and manage employee time off, time off balances, and timesheets.                                                            |
| Employee Onboarding             | Handle completion of onboarding, probation extensions, or learn how to cancel onboarding.                                         |
| Employment Lifecycle            | After successful onboarding, manage employments.                                                                                  |
| Employee Offboarding            | In case of employment termination, handle employee offboarding and resignation with ease.                                         |
| Customizations and Integrations | Endpoints for customizing data fields and managing webhook callbacks.                                                             |
| Identity Management             | List and verification identities.                                                                                                 |
| Contracts and Legal             | Endpoints for handling employment contracts, contract amendments, and legal processes like work authorization and travel letters. |
| Payroll                         | Manage payroll-related data like payslips, payroll calendars, incentives , and recurring incentives.                              |
| Expenses                        | Manage expenses, cost calculations, and get billing documents.                                                                    |
| Contractor Management           | Manage contractor invoices and amendments.                                                                                        |
| Testing                         | Tools for testing data synchronization and sandbox environments.                                                                  |
| Documents                       | Upload, retrieve, and manage files related to your company.                                                                       |
